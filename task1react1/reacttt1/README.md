# بایوآرک — نسخهٔ React

بازنویسی پروژهٔ `task1-js` با React و Vite، همراه با CSS، تصاویر، فونت‌ها، متن‌ها و آیکن‌های پروژهٔ اصلی.

## اجرای پروژه

Node.js نسخهٔ 20.19 به بالا یا 22.12 به بالا نصب باشد. سپس در پوشهٔ پروژه اجرا کنید:

```bash
npm install
npm run dev
```

آدرس نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.

## ساخت نسخهٔ نهایی

```bash
npm run build
npm run preview
```

خروجی قابل استقرار در پوشهٔ `dist` ساخته می‌شود. پروژه را از طریق وب‌سرور اجرا کنید؛ بازکردن مستقیم `index.html` با `file://` روش اجرای Vite نیست.

## قابلیت‌ها

- افزودن و حذف برچسب تشخیص و برچسب آموزشی، پیشنهاد هوشمند و اعتبارسنجی.
- افزودن و حذف مقالات، لایک و دیس‌لایک و شمارندهٔ نظرات.
- ثبت و حذف نظر، افزودن و حذف آزمون و بازگردانی حذف‌ها.
- ثبت، ویرایش، پاسخ، تغییر وضعیت و حذف بازخورد.
- ویرایشگر متن با بولد، ایتالیک، زیرخط، نقل‌قول، منشن و پیش‌نویس خودکار.
- پیوست فایل با همان رفتار نسخهٔ اصلی: ذخیرهٔ نام و حجم، تا ۵ فایل و هر فایل تا ۱۰ مگابایت.
- تب بازخوردها، لاگ فعالیت‌ها و پیوست‌ها؛ خروجی CSV و چاپ/PDF از پنجرهٔ چاپ مرورگر.
- جستجوی فارسی، حرکت با صفحه‌کلید، بازکردن بخش نتیجه و راهنمای شناور.
- نگهداری تغییرات در `localStorage` با همان کلید نسخهٔ اصلی: `bioarc_sidebar_v2_state`.

لینک‌های مشاهدهٔ مقاله و آزمون و دکمه‌های نمایشی، همان رفتار موجود در ZIP اصلی را دارند. رویداد تنظیمات به‌صورت `settings:open` روی `document` و با `detail.button` منتشر می‌شود.

برای بازنشانی همهٔ اطلاعات در کنسول مرورگر اجرا کنید:

```js
BioarcSidebar.reset()
```

## ساختار فایل‌ها

- `src/App.jsx`: صفحهٔ پرونده و باز و بسته کردن بخش‌ها.
- `src/components/Sidebar.jsx`: برچسب‌ها، مقالات، نظرات و آزمون‌ها.
- `src/components/Activities.jsx`: بازخوردها، تب‌ها، منشن‌ها و خروجی‌ها.
- `src/components/feedbackRich.jsx`: پاک‌سازی و قالب‌بندی متن غنی.
- `src/components/SearchAndTooltips.jsx`: جستجو و راهنماهای شناور.
- `src/state.jsx`: وضعیت مشترک، ذخیره‌سازی و اعلان بازگردانی.
- `src/templates/original.jsx`: قالب‌های اصلی تبدیل‌شده به JSX برای حفظ ساختار و SVGها.
- `src/style.css`: فایل CSS اصلی بدون تغییر.
- `public/image` و `public/fonts`: دارایی‌های اصلی. نسخهٔ فونت‌ها در `src/fonts` نیز برای پردازش CSS توسط Vite قرار دارد.

## بررسی انجام‌شده

وابستگی‌ها نصب و ساخت نهایی Vite با موفقیت انجام شد. خطای صفحهٔ سفید در نسخهٔ ۱٫۰٫۱ اصلاح شده است: عناصر بدون فرزند، از جمله img و input و hr، در بازنویسی درخت React بدون تغییر برگردانده می‌شوند.

نمایش اولیه در Chromium، در عرض‌های ۱۴۴۰ و ۳۹۰ پیکسل، بدون خطای JavaScript بررسی شد. مکان و اندازهٔ بخش‌های اصلی با نسخهٔ HTML اصلی برابر بود؛ مقایسهٔ تصویری موبایل نیز اختلاف پیکسلی نداشت. آزمون‌های ثبت، حذف، بازگردانی، ویرایش، رأی‌دادن، پیش‌نویس، پیوست، تب‌ها، جستجو و حفظ داده‌ها بعد از بارگذاری مجدد نیز اجرا شدند.
